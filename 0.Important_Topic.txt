1. Supervised Machine Learning :
   Supervised Machine Learning is a type of machine learning in which the model is trained using labeled data, where the correct input (X) and 
   corresponding output (Y) are already known. The model learns the relationship between input and output and then uses what it learned to 
   predict the output for new, unseen inputs.
   
   Simple words: Pehle se examples diye hote hain ki kis input ka kya correct output hai, model un examples se relationship learn karta hai.
   Example:
   1. House Price Prediction 🏠
      Model ko pehle house size aur uski actual price ka data diya jata hai. Model seekhta hai ki different sizes ke houses ki kya price hoti hai,
       aur phir new house ki price predict karta hai.
   2. Spam Email Detection 📧
      Model ko pehle emails diye jate hain jinke saath label hota hai “Spam” ya “Not Spam”. Model seekhta hai ki spam emails mein kis type ke 
      patterns hote hain, phir new email ko spam ya not spam predict karta hai.
   3. Student Result Prediction 🎓
      Model ko students ke study hours aur unke actual marks diye jate hain. Model seekhta hai ki study hours aur marks ke beech kya relationship
       hai, phir naye student ke marks predict karta hai.
   4. Disease Prediction 🩺
      Model ko patients ke symptoms aur unki already-known diagnosis di jati hai. Model symptoms aur disease ke relationship ko learn karta hai,
       phir naye patient ke symptoms ke basis par possible disease predict karta hai.

2. Unsupervised Machine Learning : No Suoervisor
   Unsupervised Machine Learning is a type of machine learning in which the model is given unlabeled data. There is no predefined output or 
   answer. The model itself finds patterns, groups, or relationships within the data.
   Simple words: Input diya jata hai, lekin correct output pehle se nahi diya hota. Model khud data ke andar pattern/group find karta hai.

   self --------- Learning

   Example:
   Machine ----- Number of Fruits
   Apple , orange , mango ------ machine ---- self learning 
   color,structure ------- Apple --- 1 group
                           orange --- 1 group(cluster)
   1. Customer Segmentation 🛒
      Shopping data diya jata hai, aur model customers ko unke purchasing behavior ke basis par different groups mein divide karta hai, 
      jaise frequent buyers, occasional buyers, aur high-spending customers.
   2. Similar Products Grouping 🛍️
      Different products ka data diya jata hai, aur model automatically similar products ko ek group mein rakhta hai.

3. Reinforcement Learning 
   Reinforcement Learning is a type of machine learning where an agent learns by interacting with an environment. It takes actions and receives 
   rewards or penalties based on those actions. Over time, it learns which actions lead to better rewards.
   working with Hit & Trail ------- penalty/reward -------- feedback

   Example:
   2 ways --- distance cover ----- shortest ----- reward ------- penalty
