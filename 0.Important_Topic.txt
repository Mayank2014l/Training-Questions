Q. inheritance:-
A. The process of acquiring properties and behaviour from oneto another class is known as inheritance.
There are five types of inheritance
1. Single level inheritance:- when a class inherites the properties of another is known as SLI.
2. Multi level inheritance:- when a class inherites the the properties of another but these class already inherited another class.
3. Multiple Inheritance:- when a class inherits more thannn one class.
4. Hierarchial Inheritance:- when a class iherited by more than one class.
5. Hybrid Inheritance:- It is a combination of heirarchial and multiple inheritance.
